
# Digital Clock ⏰

A stylish and interactive Digital Clock built using HTML, CSS, and JavaScript.  
This project allows users to set hours, minutes, and seconds, then starts a live running digital clock in real time.

## 🚀 Features
- Live Running Digital Clock
- User Input for Hours, Minutes, and Seconds
- Real-Time Time Updates
- Responsive Design
- Clean and Modern UI
- Smooth JavaScript Functionality

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 📸 Project Preview
An interactive digital clock where users can enter time values and watch the clock run live dynamically.
